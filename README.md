# cxy-tensile-cureve

拉伸应力–应变曲线批量处理基础版。从仪器导出的 Excel / CSV 中读取曲线，进行已有的曲线清理、性能计算和分组绘图。

`处理拉伸数据.py` 从本地“处理热膨胀系数”项目中独立整理而来，本次保留原脚本和算法。仓库仅包含拉伸处理代码，不包含真实实验数据、热膨胀/居里温度处理代码或生成结果。

## 在线网页

仓库包含 Streamlit 在线工具，支持批量上传 `.xlsx`、`.csv` 或保留目录结构的 `.zip`，网页中预览曲线和性能表，并下载单项结果或完整 ZIP。处理完成后可自由多选曲线，选择“叠加对比”或“单独出图”，生成白底、简洁坐标轴、色盲友好配色的 300 dpi PNG，并可标注 Rp0.2、Rm、Ag（均匀延伸率）和 At（断裂延伸率）位置。

```powershell
python -m pip install -r requirements.txt
streamlit run streamlit_app.py
```

打开终端显示的本地网址即可使用。也可在 [Streamlit Community Cloud](https://share.streamlit.io/) 选择此 GitHub 仓库、`main` 分支和入口文件 `streamlit_app.py`，部署为可分享的网址。建议部署时选择 Python 3.12；`packages.txt` 会为 Linux 安装 Noto CJK 中文字体。

网页每次处理使用独立临时目录，成功、失败或超时后清理。下载包不包含原始上传文件；服务日志仍可能包含文件级错误信息，涉及保密实验时应按所在单位的数据规则选择部署环境和访问范围。

- 单个上传项不超过 20 MiB，总计不超过 60 MiB。
- ZIP 展开后不超过 100 MiB，最多包含 30 个数据文件；不接受嵌套 ZIP、越界路径或符号链接。
- 散装 CSV 会自动适配为仪器 `_Exports` 目录。需要同目录汇总表匹配或保留批次结构时，请上传 ZIP。
- 上传文件变化后，页面会清除旧处理结果，避免把旧结果误认为当前输入。
- “单独出图”每次最多选择 24 条曲线；需要更多时可分批生成。“叠加对比”不受此项限制。
- “运行合成示例”只用于体验处理流程，不代表真实实验精度。

## 安装与运行

建议 Python 3.10 或更新版本；本次验证环境为 Python 3.12.7、openpyxl 3.1.5、Pillow 10.4.0。脚本不依赖同目录的其他 Python 文件。

```powershell
python -m pip install -r requirements.txt
python "处理拉伸数据.py" --help
python "处理拉伸数据.py" --input "D:\实验数据\拉伸数据" --output "D:\实验数据\拉伸曲线输出_本次"
```

也可使用相对于当前工作目录的路径：

```powershell
python "处理拉伸数据.py" --input "./data" --output "./results"
```

请显式指定输入与输出目录。原脚本默认值仍指向原机器的 `C:\Users\Administrator\Desktop\项目\实验数据` 下的“拉伸数据”和“拉伸曲线输出”。

**输出目录应专用于本脚本：每次运行会删除该目录下 `by_file/*.png`、`by_group/*.png`、`by_group/*.xlsx`，并覆盖 `curve_index.csv`。需要保留历史结果时，为每次运行指定新的输出目录。**

## 输入格式

### Excel（`.xlsx`）

递归扫描输入文件夹，跳过 `~$` 临时文件及输出文件夹内的文件。曲线工作表采用相邻的“应变、应力”列对：

| 行 | 应变列 | 应力列 |
| --- | --- | --- |
| 第 1 行 | `[Test Run 1]` 或曲线名称 | 可为空 |
| 第 2 行 | `%` 或 `mm/mm` | `MPa`、`kN/mm²` 或 `kN/mm2` |
| 第 3 行起 | 应变数值 | 应力数值 |

同一工作表可包含多组列对，每条曲线至少需要 5 个有效点。`mm/mm` 乘以 100 转为百分数应变；`kN/mm…` 乘以 1000 转为 MPa。

可选仪器汇总表包含“名称、试样标识、Rp0.2、Rm、At”等表头，名称使用 `Test Run N`。脚本可按同文件夹和试验编号关联样品信息；若同文件夹中编号重复，信息可能被覆盖，请避免把不同批次的同编号试验混放。

### CSV（仪器 `_Exports` 格式）

仅处理**直接父目录名称以 `_Exports` 结尾**的 `.csv`，例如：

```text
data/
  batch_01/
    demo_Exports/
      sample_01.csv
```

文件使用逗号分隔，曲线区域包含中文表头行、单位行和数值行，例如：

```csv
时间,拉伸应变,应力
s,%,MPa
0,0,0
0.1,0.002,4
0.2,0.004,8
```

以上仅为格式片段，实际数据仍需至少 5 个有效点，并提供足够点数用于弹性段拟合。单位行必须同时包含 `%` 与 `MPa`；CSV 分支不做单位换算，不支持任意两列 CSV。优先读取“拉伸应变”和“应力”列，支持 UTF-8-BOM、GBK 等编码。若缺少“试样标识”元数据，以文件名作为样品名。

## 输出

| 路径 | 内容 |
| --- | --- |
| `by_file/*_all_curves.png` | 按来源文件/导出目录组合的曲线图 |
| `by_group/*_curves.png` | 按样品组汇总的曲线图 |
| `by_group/*_curves.xlsx` | 分组性能表 |
| `curve_index.csv` | 来源、计算性能、原仪器值、处理记录、质量标记及图片路径 |

网页的自定义绘图使用本次会话中的清理后曲线点，默认将所选曲线叠加在同一张图；切换为“单独出图”后可下载图片 ZIP。性能点标注默认开启：Rp0.2 使用空心圆，Rm 使用菱形，Ag 使用横轴三角形和引导线，At 使用空心方块；缺失指标不标注。会话绘图数据不会作为额外文件加入完整结果 ZIP。

样品名以 `C数字` 开头时按该编号分组；其他名称取首个连字符之前的部分。分组表包含 Rp0.2、Rm、均匀延伸率、断裂延伸率和 E。索引使用 UTF-8-BOM 编码，原仪器汇总值单独保留在 `instrument_*` 列。

运行结束会打印文件数、曲线数、图片数和 `error_count`。读取异常会写入索引中 `sample_id=ERROR` 的行；不符合格式的文件可能被跳过，需同时检查曲线数量。当前不导出清理后的逐点数据，也不对 Excel / CSV 中重复出现的同一试验自动去重。

## 基础版处理规则

- 清理低载荷起始段并将应变归零，处理峰后掉载、末端跳点、应变回退与引伸计滑移。
- 峰值后若在极小应变增量内出现近乎竖直的显著掉载，视为视频引伸计捕捉到的断裂瞬间；曲线在掉载前一个点截止，At 和断裂标记均取该点。正常的缓慢颈缩下降段保留。
- 由处理后的曲线重新计算性能：Rm 为最大应力，均匀延伸率为峰值位置应变，At 为最后保留点的应变。
- E 来自自动选择的线性拟合窗口；Rp0.2 来自 0.2% 偏移线交点。拟合或屈服判据不满足时，字段可能留空，并在索引中保留标记。
- 滑移处理使用 **0.05 个百分点**的相邻应变跳变阈值，正常采样步长过大也可能触发修正，应检查原曲线与处理记录。
- `fracture_mode` 是基于延伸率阈值的启发式分类，不代表断口学鉴定。自动计算结果需要结合试验条件、原始曲线及仪器结果核对，不构成标准符合性或精度验证。

图像采用论文式白底、左/下坐标轴、紧凑图例和色盲友好配色，坐标名称使用英文。字体优先使用部署环境指定字体、Windows 微软雅黑或 Linux Noto Sans CJK；都不可用时退回 Pillow 默认字体。
